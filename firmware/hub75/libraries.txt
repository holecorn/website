  Adafruit GFX Library                       1.12.6   Adafruit   <- transitive
  Adafruit BusIO                             1.17.4   Adafruit   <- transitive

The bottom two are not used by any code here. The HUB75 library's own header
includes Adafruit_GFX.h, so the build fails at the first #include without it, and
GFX in turn pulls BusIO. Library Manager installs them for you; arduino-cli does
not, which is how they came to be missing from this list for so long. Don't drop
them for being unreferenced.
